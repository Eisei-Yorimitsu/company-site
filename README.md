# スカイライン・テクノロジーズ 企業サイト

架空のソフトウェア開発会社「スカイライン・テクノロジーズ」のコーポレートサイトです。
クラウド・AI・モバイルを軸に企業のデジタル変革を支える会社という設定で、1枚の `index.html` に HTML・CSS・JavaScript をすべて収めています。

> ※ 掲載している企業・事例・お知らせはすべて架空のものです。

## 概要

### ページ構成

| セクション | 内容 |
| --- | --- |
| ヘッダー / お知らせバー | ナビゲーション、自動で切り替わるお知らせ（閉じるボタン付き） |
| ヒーロー | キャッチコピー「テクノロジーで、ビジネスの視界を広げる。」と実績の数値（カウントアップ表示） |
| 事業内容 (`#services`) | クラウド開発、AI・データ活用、アプリ開発 |
| 私たちについて (`#about`) | 企業理念・メッセージ |
| 導入事例 (`#works`) | 取引先での導入事例 |
| 開発の流れ (`#process`) | プロジェクトの進め方 |
| お知らせ (`#news`) | 最新ニュース |
| お問い合わせ (`#contact`) | 問い合わせフォーム（デモ） |
| フッター | サイトマップ・コピーライト |

### 主な特徴

- **単一ファイル構成**：ビルドもサーバーも不要で、`index.html` を開くだけで表示できます
- **レスポンシブ対応**：スマートフォンではハンバーガーメニューに切り替わります
- **ダークモード対応**：OS の外観設定（ライト／ダーク）に合わせて配色が変わります
- **アニメーション**：スクロールに合わせたフェードイン、数値のカウントアップ
- **アクセシビリティ**：ARIA 属性やキーボード操作に配慮しています

### 外部リソース

- フォント：Google Fonts（Inter / Noto Sans JP）

オフラインでも表示はできますが、その場合はフォントが OS の標準フォントになります。

## ブラウザで index.html を開く手順

### 方法 1：ファイルを直接開く（いちばん簡単）

1. Finder（Windows ではエクスプローラー）でこのフォルダを開きます
2. `index.html` をダブルクリックします
3. 既定のブラウザでサイトが表示されます

ブラウザのウィンドウに `index.html` をドラッグ＆ドロップしても開けます。

### 方法 2：ターミナルから開く

```bash
# macOS
open index.html

# Windows（PowerShell）
start index.html

# Linux
xdg-open index.html
```

### 方法 3：ローカルサーバーで開く（任意）

実際の Web サーバーに近い環境で確かめたいときは、簡易サーバーを起動します。

```bash
# Python 3 がある場合
python3 -m http.server 8000
```

起動したら、ブラウザで <http://localhost:8000> にアクセスします。止めるときはターミナルで `Ctrl + C` を押します。

## 注意事項

- お問い合わせフォームはデモです。送信ボタンを押すと完了メッセージが表示されますが、データはどこにも送信されません。
- 推奨ブラウザは Google Chrome、Safari、Microsoft Edge、Firefox の最新版です。
